About RoadLens

Project goals, architecture, accessibility, privacy, security and a simple future roadmap.

Project purpose

RoadLens Australia was designed as a student web-technology project that demonstrates semantic HTML5, responsive CSS3, JavaScript-driven interactivity, dataset integration, accessibility-aware interface design and basic web-security principles.

Design principles

  • Focus: one primary analytical task per page.
  • Accessibility: skip link, semantic headings, keyboard-focus states, table alternatives, responsive target sizes and reduced-motion support.
  • Privacy: no login, no analytics, no tracking pixels and no collection of sensitive data.
  • Security: restrictive Content Security Policy, no third-party scripts, no inline JavaScript and safe external-link attributes.
  • Future-ready: progressive-web-app manifest and service worker when served over HTTP/HTTPS.

Accessibility statement

The prototype targets WCAG 2.2 Level AA design practices where practical for a student project. It uses visible keyboard focus, semantic landmarks, text alternatives, high-contrast colour choices, responsive touch targets and accessible data tables alongside charts.

Formal conformance would still require manual assistive-technology testing and a complete WCAG audit before production release.
