# Privacy Design

RoadLens Australia applies data minimisation.

- The application uses aggregate public road-safety statistics rather than individual fatality records.
- There are no accounts, marketing profiles, trackers, analytics services, or persistent feedback records.
- `localStorage` is used only for the user's theme preference.
- The local feedback form displays a confirmation and resets without sending the content to a server.

If future versions introduce accounts, analytics, remote feedback, or live APIs, the privacy notice and technical controls must be reviewed before deployment.
