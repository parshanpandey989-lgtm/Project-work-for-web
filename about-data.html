About the data

Where the statistics come from, how they are integrated, and what users need to know before interpreting them.

Source and integration

The prototype uses aggregate statistics published by the Australian Government Department of Infrastructure, Transport, Regional Development, Communications, Sport and the Arts on the National Road Safety Data Hub. Values are stored locally in a structured JavaScript data object so every chart, KPI and table is generated from the same source layer.

Open official source ↗

Why aggregate data?

RoadLens deliberately avoids reproducing individual-level fatality records. The website needs trend and comparison functionality, not personal-level detail. This reduces privacy risk while still meeting the educational goal of data-driven web development.

Limitations shown to users

Transparent limitations are part of the design, not an afterthought.

Preliminary recent figures

The source notes that recent road-death data are preliminary and subject to revision.

Unknown categories

Some totals include unknown values. Remoteness data in particular should be interpreted cautiously because the Unknown category increased.

Descriptive, not causal

Charts show patterns and associations. They should not be read as proving why a crash occurred.
